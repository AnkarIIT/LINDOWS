# LINDOWS references

Reference material for the from-scratch OS build. Collected here from public
sources (OSDev wiki) so the team has a stable reading list.

Core reading
- OSDev wiki — Bare Bones (32-bit kernel from scratch)
  https://wiki.osdev.org/Bare_Bones
- OSDev wiki — Creating a 64-bit kernel
  https://wiki.osdev.org/Creating_a_64-bit_kernel
- OSDev wiki — Going Further on x86
  https://wiki.osdev.org/Going_Further_on_x86
- OSDev wiki — Tutorials (index)
  https://wiki.osdev.org/Tutorials
- OSDev wiki — Boot Sequence
  https://wiki.osdev.org/Boot_Sequence
- Intel SDMs (software developer manuals) — authoritative CPU behavior
  https://www.intel.com/content/www/us/en/developer/articles/technical/intel-sdm.html

Toolchain
- Theseus OS book — building an x86_64-elf GCC cross compiler
  https://www.theseus-os.com/Theseus/book/c/cross_compiler.html
- Lord Milton / lordmilko — prebuilt i686-elf-tools for Windows
  https://github.com/lordmilko/i686-elf-tools
- Perception OS — building on Windows (toolchain links)
  https://github.com/AndrewAPrice/Perception/blob/master/building.md

Bootloaders
- Limine bootloader (64-bit capable)
  https://github.com/limine-bootloader/limine
- BOOTBOOT (alternative)
  https://gitlab.com/bztsrc/bootboot

This folder is intentionally free of copyrighted material — URLs only.
